Read19 是我做的围棋复盘工具，也是一个可以独立接入的云端 KataGo 服务。你可以打开网页导入棋谱，查看候选着、胜率和目差；也可以继续使用 KaTrain 等围棋软件，把分析交给云端。

官网：[read19.com](https://read19.com/)。

## 从一份棋谱开始

用 AI 复盘，除了得到分析结果，还要能沿着自己的疑问继续看棋。哪一步开始吃亏？实战选择和候选着差在哪里？换一个下法，对方会怎样应对？

Read19 把棋盘、整局趋势和变化图放在同一个复盘界面里。导入 SGF 后，可以按胜率与目差的变化找到关键手，再回到对应局面查看候选着。点进一条变化，棋盘和分析结果会跟着切换，也可以继续落子，比较自己的想法与 KataGo 的判断。

实战棋谱和试走变化分别保留，研究另一种下法时，不会覆盖原来的对局。整理完以后，还可以导出 SGF。

如果是第一次使用，可以按这个顺序试：

1. 打开[复盘页面](https://read19.com/review)，导入一份自己的 SGF。
2. 看整局胜率、目差趋势，选一处变化明显的地方。
3. 回到那一步之前，对比实战落子和几个候选着。
4. 沿变化图往下看，再试着落下自己想走的一手。

胜率和目差适合放在一起看。领先很多时，胜率的变化未必能说明一手棋损失了多少目；局面接近时，几目的变化又可能显著影响胜率。分析结果能帮助定位问题，具体为什么成立，还是要回到棋盘和变化里看。

## 分析在云端，本机负责看棋

KataGo 在服务器上运行，浏览器或应用负责显示棋盘和分析结果。本机不需要准备 GPU、安装驱动或下载引擎权重。

这也意味着，云端分析需要网络连接。搜索量越大，引擎通常能更充分地研究局面，但不会因此保证每个复杂局面都有唯一、确定的答案。

除了复盘，Read19 还有[在线对局](https://read19.com/play)入口，可以和 KataGo 下一盘，再回头研究对局。

## 继续用 KaTrain，或者接入自己的工具

如果你已经习惯了 KaTrain，Read19 也可以只提供分析引擎。在账户里创建个人 API Token，按照[开发者说明](https://read19.com/developers)配置 WSS 地址，就能让支持远程引擎的客户端连接云端 KataGo。

对自己写工具的人，Read19 提供两种接口：

- **WebSocket**：使用 KataGo Analysis Engine JSON，适合持续接收分析结果。
- **REST**：适合单次局面分析，以及脚本和自动化任务。

另外还有 [Read19 CLI](https://read19.com/cli)。它在本机做协议桥接，让 Sabaki、q5Go、Lizzie 等支持 GTP 的桌面软件调用云端引擎；使用 Analysis Engine 的程序和脚本也可以走 JSONL 桥接。这样可以保留原来的棋盘和操作方式。

Token 是调用服务的凭据，适合按设备分别创建，停用一台设备时可以单独吊销。不要把个人 Token 放进公开的棋谱、截图或代码仓库。

## 网页、电脑和手机

网页版可以直接使用。官网也提供 Windows、Android、macOS 安装包，以及 iPhone / iPad 的 App Store 入口。各平台的当前版本和下载方式统一放在[官网下载区](https://read19.com/#download)。

棋谱先保存在本机；登录后，可以通过 Read19 云棋谱库在不同设备之间同步。涉及重要棋谱时，也可以保留一份导出的 SGF，方便在其他围棋工具里打开。

## 免费额度与分析单位

截至本文发布时，Free Beta 每月提供 **100,000 个 KataGo 分析单位**，每个局面最高 1,000 个分析单位，可以同时进行 3 个分析任务。免费额度可以用于 Read19 网页和应用，也可以用于 KaTrain 或自己的工具。

这里的“分析单位”衡量的是 KataGo 引擎内部的树搜索计算，不是网页访问次数，也不是 API 请求次数。分析更多局面、提高单个局面的搜索量，都会使用相应额度。

需要更多计算量时，官网提供一次性购买的分析单位，购买额度永久保留。免费规则、价格和可用付款方式可能调整，使用前以[官网额度与价格说明](https://read19.com/#pricing)和账户页为准。

## 入口和反馈

想先看看复盘体验，可以直接打开 [Read19 复盘](https://read19.com/review)。如果希望保留现有客户端，就从[连接说明](https://read19.com/developers)或 [CLI 下载页](https://read19.com/cli)开始。

遇到问题可以查看[服务状态](https://read19.com/status)，或通过[支持页面](https://read19.com/support)反馈。附上使用平台、发生时间和复现步骤，会更容易定位问题。
